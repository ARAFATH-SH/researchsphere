# ResearchSphere

An AI-powered research collaboration and networking platform.

| Folder | What it holds |
| --- | --- |
| `frontend/` | Next.js web client (TypeScript) |
| `backend/` | Go API server and database migrations |
| `ai/` | Python AI service (embeddings, matching, writing assistant) |
| `sync/` | Hocuspocus server for real-time editing |
| `compile/` | LaTeX compile service |
| `docs/` | SRS, API contract and decisions |
